# TeamScheduler

Веб-приложение для управления расписаниями и совместной работы в командах. Позволяет создавать расписания, планировать события, делиться расписаниями с другими пользователями и командами.

## Возможности

- **Расписания и события** - создание, редактирование и удаление расписаний и событий с просмотром в календаре
- **Повторяющиеся события** - настройка повторения (ежедневно, еженедельно, ежемесячно, ежегодно)
- **Участники событий** - добавление участников с RSVP-статусами (ожидает, принят, отклонён, предварительно)
- **Детекция конфликтов** - автоматическое обнаружение пересечений событий по времени
- **Команды** - создание команд с ролями admin/member, управление участниками
- **Шеринг расписаний** - передача расписаний отдельным пользователям или командам с правами просмотра или редактирования

## Стек

Django 6 - Python 3.14 - SQLite
